# ExileGames 🎮

**Built by gamers, for gamers.**

ExileGames is a gaming community project designed to bring PC and console gamers together.

## Vision
Create a modern, futuristic gaming platform where players can discover sessions, find teammates, and connect with other gamers.

## Current prototype
- Neon-inspired gaming interface
- Create gaming sessions
- Browse available sessions
- Join and leave locally stored sessions
- Save session data on your computer

## Development
The current prototype uses Python and Tkinter.

**Note:** Online accounts, live multiplayer services, and real-time cross-platform features are planned for future development and are not yet implemented.

## Our goal
Build ExileGames into a gaming community for all gamers.
